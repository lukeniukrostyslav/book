# ORIGINALITY GUARD — FORBIDDEN / HIGH-RISK PATTERNS

Avoid using these as the core explanation:
- magic school
- dragon academy
- fae court
- chosen one
- prophecy
- vampire romance
- ancient gods return
- simple world-is-illusion
- government hides the truth as sole mystery
- simple lost ancient civilization
- last descendant
- memory loss as the main twist
- ordinary fantasy detective
- magical artifact as the complete plot engine
- language as a simple magic system
- memory as the core magic mechanism
- belief creates magic
- time travel or parallel world as the central mechanism
- Avatar-like spiritual ecosystem
- everything is connected as the final answer

## Positive originality anchors
- civilization-wide practical Trace technology;
- competing institutions with genuinely useful but incomplete models;
- fair-play mystery;
- structural transition rather than erased history;
- ordinary professional protagonist;
- ethical problem of acting under incomplete models;
- no chosen hero or metaphysical favoritism.

## Stress-test rule
Every major new idea must be checked for similarity to familiar fantasy tropes, philosophical derivation risk, mechanical necessity, effect on civilization logic and effect on Book 1 fairness.
