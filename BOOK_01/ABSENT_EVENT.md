# ABSENT EVENT / STRUCTURAL TRANSITION

Status: CANON CANDIDATE — requires final gate

## Rejected explanations
- erased history
- forgotten person
- simple censorship
- time travel
- future event
- parallel reality
- ancient god intervention
- lost civilization as sole explanation
- memory magic

## Current hypothesis
Some anomalies may represent a change in the structure of relations without a conventional event/object that can be identified as the source.

The key mystery is not necessarily:
"What event happened between A and B?"

It may become:
"What if there was no ordinary event between A and B?"

## Structural Transition
Working definition:
A transition in the relational structure of the world that is real and leaves Trace, but cannot be represented by current human event categories as an ordinary event.

## Book 1 knowledge boundary
Readers should know:
- the Trace is real;
- no physical interaction explains it;
- historical analogues exist;
- known relation classes fail;
- prior researchers encountered the same boundary.

Readers should NOT receive a complete explanation of Level III/Deep Structure in Book 1.
